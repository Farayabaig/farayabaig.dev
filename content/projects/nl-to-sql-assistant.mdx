## The problem

Most people who need data cannot write SQL, and those who can still need to know the schema. A natural language interface removes that barrier, if it is safe and its output is predictable.

## Key engineering decisions

<Decision title="Agents with narrow roles">
CrewAI made it natural to split schema understanding from query writing, which keeps each prompt small and each failure easy to locate.
</Decision>

<Decision title="Structured JSON output">
Returning **structured JSON** instead of free text means the results can feed other tools and UIs directly.
</Decision>

<Decision title="Safety on the database side">
An LLM writing SQL should never be trusted with write access. A read only database role is the guardrail that cannot be prompt injected away.
</Decision>
